# Support

Choose the channel that matches the request so maintainers can respond efficiently.

## Questions and Setup Help

Use [GitHub Discussions](https://github.com/CRSD-Lau/deep-live-cam/discussions) for installation questions, hardware compatibility, workflow advice, and ideas that are not yet confirmed bugs.

Before posting, review:

- [the README](README.md);
- [DirectML setup and verification](docs/DIRECTML_TESTING.md);
- [OBS and virtual-camera troubleshooting](docs/OBS_VIRTUAL_CAMERA.md);
- existing discussions and issues.

## Reproducible Bugs

Use the repository's bug-report form when the latest release behaves incorrectly. Include the application version, Windows version, GPU and driver, selected provider, reproducible steps, and sanitized logs.

Do not attach private faces, videos, full home-directory paths, credentials, or model/checkpoint files.

## Feature Requests

Use the feature-request form for a concrete user problem and proposed outcome. Larger ideas may be moved to Discussions until the scope and validation plan are clear.

## Security Vulnerabilities

Do not disclose security issues publicly. Follow [SECURITY.md](SECURITY.md) and use [private vulnerability reporting](https://github.com/CRSD-Lau/deep-live-cam/security/advisories/new).

## Upstream Questions

This repository is a Windows-focused derivative. Issues that reproduce unchanged in the upstream project may ultimately belong in [hacksider/Deep-Live-Cam](https://github.com/hacksider/Deep-Live-Cam), but please avoid filing the same report in both repositories simultaneously.
